Data Sources and Methodology:

* Data sources: job postings published on the official career sites of S&P 500 companies (constituents as of ; Berkshire Hathaway is excluded). Coverage by company is listed under Source Coverage above.

Postings come only from each company's official career site. Collectors call the site's own job API where one exists (Workday, Oracle Recruiting, SuccessFactors, Eightfold, Jibe, amazon.jobs) and otherwise read the schema.org JobPosting data on each posting page. Postings without a date on the site are left out. Sites that refuse automated access are listed as blocked, not estimated.

Update schedule: the data is refreshed weekly. Collection starts every Monday at 2:00 a.m. Eastern Time (New York), and the dashboard updates when it finishes, usually a few hours later. The date in the top-right corner shows the latest update.

Each collection run is a snapshot. A posting keeps the date it was first seen; one that disappears from a later run is counted as closed, and its title is greyed out with the date it was last seen instead of linking to a page that no longer exists. Only postings dated October 1, 2026 or later are included. A posting dated after the day it was collected (a scheduled start date on some sites) is dated to the collection day.

Occupation groups follow the 2018 Standard Occupational Classification (SOC) major groups, assigned by auditable title rules with the company's own job family as a fallback. Pay is the posted range, annualized for comparison; it is not actual earnings. Skills and licenses are matched against a fixed dictionary, so a skill the dictionary lacks will not appear. "Not specified" means the posting does not specify.
