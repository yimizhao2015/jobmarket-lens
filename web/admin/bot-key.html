Makes the Ed25519 key the collector signs its requests with. The key is made in this browser and is never sent anywhere. Copy it into the two secrets below, then close this page.

Private key (secret: never paste it in chat, email or a file in the repository):

  1. GitHub: jobmarket-lens, Settings, Secrets and variables, Actions, New repository secret. Name WEB_BOT_AUTH_KEY, value: the key above.
  2. Cloudflare: Workers & Pages, jobmarket-lens, Settings, Variables and Secrets, Add, type Secret. Name WEB_BOT_AUTH_KEY, the same value. Then redeploy.
